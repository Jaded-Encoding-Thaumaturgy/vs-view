# VSView Graph

Interactive dependency graph visualizer for [vsview](https://github.com/Jaded-Encoding-Thaumaturgy/vs-view),
built on [vsgraph](https://github.com/Ichunjo/vs-graph) and Cytoscape.js.

## Documentation

Usage and configuration details are available in the [documentation](https://jaded-encoding-thaumaturgy.github.io/vs-view/plugins/second-party/#dependency-graph)
